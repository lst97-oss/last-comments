```html
<link rel="stylesheet" href="https://unpkg.com/@lst97-oss/last-comments-widgets/dist/vanilla/styles.css" />
<div data-lc-comments data-lc-site="demo" data-lc-base-url="https://comments.example.com"></div>
<script type="importmap">
  {
    "imports": {
      "marked": "https://unpkg.com/marked/lib/marked.esm.js"
    }
  }
</script>
<script type="module" src="https://unpkg.com/@lst97-oss/last-comments-widgets/dist/vanilla/index.js"></script>
```

`data-lc-site` is the site key configured on your last-comments server. `data-lc-base-url` should point at a same-origin proxy of the API — see [Install & server setup](/docs/install).

<Callout type="info" title="Two files, one import map">
  The widget needs the compiled stylesheet at `dist/vanilla/styles.css` and the bundle at `dist/vanilla/index.js`. The `importmap` entry for `marked` is required — the bundle imports it rather than bundling a Markdown parser. Nothing else is needed: the widget bundle and the theme are self-contained.
</Callout>

## Attributes

These attributes set the same options as the props. Callbacks, `settings`, `pageId` and `fetchImpl` are JavaScript-only.

| Attribute | Prop | Default |
| --- | --- | --- |
| `data-lc-site` | `site` | required |
| `data-lc-base-url` | `baseUrl` | required |
| `data-lc-page-url` | `pageUrl` | `location.href` |
| `data-lc-limit` | `limit` | `20` |
| `data-lc-lazy` | `lazy` (presence turns it on) | off |
| `data-lc-theme` | `theme` (`light` \| `dark` \| `system`) | `system` |
| `data-lc-viewer-user-id` | `viewerUserId` | guest |
| `data-lc-viewer-role` | `viewerRole` (`admin`) | — |
| `data-lc-math` | `math` (presence turns it on) | off |
| `data-lc-mermaid` | `mermaid` (presence turns it on) | off |
| `data-lc-no-code-highlight` | `codeHighlight` (presence turns it off) | highlight on |
| `data-lc-anon-edit-window-minutes` | `anonEditWindowMinutes` | `10` |
| `data-lc-action-mode` | `actionMode` (`icon` \| `icon-text` \| `text`) | `icon-text` |
| `data-lc-body-limit` | `bodyLimit` | the site's limit (`10000` if unknown) |
| `data-lc-sign-in-url` | `signInUrl` (the sign-in card's button, on `login` and `private` sites) | — (the button starts sign-in in place) |
| `data-lc-turnstile` | `turnstileSiteKey` | — |
| `data-lc-turnstile-theme` | `turnstileOptions.theme` (`auto` \| `light` \| `dark`) | widget light/dark mode |
| `data-lc-turnstile-size` | `turnstileOptions.size` (`normal` \| `compact` \| `flexible`) | `normal` |
| `data-lc-turnstile-appearance` | `turnstileOptions.appearance` (`always` \| `interaction-only`) | `interaction-only` |
| `data-lc-turnstile-language` | `turnstileOptions.language` | browser language |

The Turnstile rows only apply when `data-lc-turnstile` (the site key) is set. Cloudflare owns the challenge iframe, so `theme`, `size`, `appearance` and `language` are the only knobs; style the `.lc-turnstile` container instead.

Signed-in authors may edit their own comments any time; a guest may edit only from the browser that stored the key returned when they posted, inside the anonymous window above.

## Programmatic mounting

`mountComments(element, options)` and `renderCommentViewer(element, options)` are exported from `@lst97-oss/last-comments-widgets/vanilla`. Both accept `{ themeVars: brand }` alongside the same options as the attributes above.

```ts
import { mountComments } from '@lst97-oss/last-comments-widgets/vanilla'

mountComments(document.querySelector('#comments')!, {
  site: 'demo',
  baseUrl: '/',
  theme: 'system',
  themeVars: brand,
})
```

Themes reach plain HTML through `data-lc-theme-var-*` and `data-lc-theme-dark-var-*` attributes — see [Theming](/docs/theming).
