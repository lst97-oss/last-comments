Every failure renders one block — alert icon, a title that names the situation, the API's own message when it is human-readable, and an action only when one helps (`Try again` for retryable failures, `Sign in` when an account is required). It appears for:

- list and viewer load failures (including the viewer's retry),
- composer post/reply failures,
- edit/delete/vote failures,
- moderation actions,
- sign-in/sign-out failures.

Busy/blocked/locked pages keep their dedicated states.

<Callout type="info" title="Hidden is not an error">
  The [filter plugin](/docs/plugins#filter-hide-for-review-screening) holds violations for review instead of rejecting them: a flagged comment still posts (`200`) with `status: 'hidden'`. Hidden rows never produce an error block — they vanish from the public thread and wait in `/moderation`.
</Callout>

## describeError

The copy comes from `describeError(error, overrides?)` in `@lst97-oss/last-comments-widgets/client` (exported and tested): it maps each `ApiError.code` to `{ code, title, message, action }`, turns a failed `fetch` into "Couldn't reach the comments service", ignores the synthesised `request failed with 500` message, and takes `overrides.title` only for codes that have no scenario-specific copy — widgets pass action framing such as `"Your comment wasn't posted"`. Hosts rendering their own UI can call it directly.

```ts
import { describeError } from '@lst97-oss/last-comments-widgets/client'

const copy = describeError(error, { title: "Your comment wasn't posted" })
```

## Styling and asserting

The rendered block carries `data-lc-error` and `data-error-code` (empty when the failure was not from the API) so you can style or assert on it.

```css
[data-lc-error] {
  border-color: var(--destructive);
}
[data-error-code="ORIGIN_NOT_ALLOWED"] {
  /* the page origin is not an allowed origin of the site */
}
```

## Error codes

### Request errors

| Code | Meaning |
| --- | --- |
| `VALIDATION_ERROR` | The request body or query did not pass validation. |
| `MALFORMED_JSON` | The request body was not valid JSON. |
| `UNAUTHENTICATED` | The action requires a signed-in session, or a key with the matching `comments:*` scope (401). On a `login` site a read is open and a write needs a session or key; on a `private` site a read needs one too. |
| `ORIGIN_NOT_ALLOWED` | The page origin is not an allowed origin of the site (403). |
| `SITE_NOT_FOUND` | The `site` key does not exist on the server. |
| `FORBIDDEN` | The account lacks permission for this action. On a site with `gatewayOnly` enabled, a caller without a site-bound key gets this code, even with a registered Origin (403). |

### Content and verification errors

| Code | Meaning |
| --- | --- |
| `USER_BLOCKED` | The account is blocked from the site. |
| `PAGE_LOCKED` | The thread is locked and accepts no new comments. |
| `PARENT_NOT_FOUND` | The reply's parent comment does not exist. |
| `COMMENT_NOT_FOUND` | The comment does not exist. |
| `COMMENT_TOO_LONG` | The body is longer than the site's comment limit (400). The default limit is 10,000 characters; a site can lower it. |
| `COMMENT_VERIFICATION_FAILED` | The Turnstile challenge was rejected. |
| `COMMENT_VERIFICATION_UNAVAILABLE` | Verification is required but no provider is configured (503). |
| `EDIT_WINDOW_EXPIRED` | The anonymous edit window has closed. |
| `SIGN_IN_UNAVAILABLE` | The API could not start the sign-in flow. |
| `SIGN_OUT_FAILED` | The sign-out request failed. |

The list is `ApiError.code` in `packages/client/src/index.ts`.

## API codes

The server also returns codes the widgets never show, because the widgets send requests that cannot produce them. Your own server sees these from the API, in the `error.code` field.

| Code | Status | Meaning |
| --- | --- | --- |
| `RATE_LIMITED` | 429 | Too many comment operations for this visitor, site and operation. The response has `Retry-After`. |
| `RATE_LIMIT_UNAVAILABLE` | 503 | The rate-limit store could not be read or written. Writes fail closed. |
| `COMMENT_PLUGIN_UNAVAILABLE` | 503 | A comment plugin did not answer in time. Retry shortly. |
| `DATABASE_UNAVAILABLE` | 503 | The database is temporarily unavailable. Retry shortly. |
| `OG_RENDER_BUSY` | 503 | The social card renderer is at its concurrency limit. The response has `Retry-After`. |
| `AUTHOR_NAME_REQUIRED` | 400 | A guest comment needs an `authorName`. A signed-in account does not. |
| `INVALID_PAGE_URL` | 400 | `url` is not an absolute HTTP(S) URL. |
| `INVALID_PAGE_KEY` | 400 | `pageKey` is not a lowercase slug of up to 120 characters. |
| `PAGE_KEY_MISMATCH` | 409 | The `pageKey` belongs to a different thread from the `url`. Threads are never merged. |
| `PAGE_ORIGIN_NOT_ALLOWED` | 400 | A key tried to open a thread on a page URL whose origin the site has not registered. Register the origin first. |
| `PAGE_NOT_FOUND` | 404 | The page does not exist on this site. |
| `PAGE_UNAVAILABLE` | 500 | The page could not be created for the comment. Retry. |
| `BODY_TOO_LARGE` | 413 | The JSON body is over 128 KiB. |
| `UNSUPPORTED_MEDIA_TYPE` | 415 | The request body is not `application/json`. |
| `INVALID_API_KEY` | 401 | The key is missing, invalid, revoked or expired. |
| `API_KEY_NOT_FOUND` | 404 | No key with that id exists for this scope, or it belongs to another site. |
| `INVALID_SCOPE_SET` | 400 | The scopes do not fit the key type: a site key takes page and comment scopes, an instance key takes `sites:*`. |
| `NOTHING_TO_UPDATE` | 400 | A key update passed neither `scopes` nor `enabled`. |
| `SITE_KEY_EXISTS` | 409 | A site with that key already exists. |
| `SETUP_UNAVAILABLE` | 409 | The first-admin setup has already been used. |
| `ADMIN_SIGNUP_FAILED` | 400 | The first admin account could not be created. |
| `FEATURE_DISABLED` | 403 | Voting is off for this site (`votesEnabled`). Votes already cast are kept. |
| `AUTH_PROVIDER_DISABLED` | 404 | The built-in login endpoints are off because `better-auth` is not in the enabled providers. Sign in through the configured provider. |
| `OPENAPI_DISABLED` | 404 | The OpenAPI document and its reference page are not installed on this server. |
| `INTERNAL_ERROR` | 500 | An unexpected failure. The message is generic; the request ID in `x-request-id` finds the log line. |
