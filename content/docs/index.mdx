`@lst97-oss/last-comments-widgets` ships the same comment widget implemented natively for React, Vue, Angular and plain HTML, on one framework-free API client and one self-contained theme. Install only the framework you use; every other framework's libraries are optional peers and are never loaded.

<Callout type="info" title="Registered origins can call the API directly">
  Widget requests send credentials. The API answers only origins a site has registered, with credentialed CORS. A page on the same registrable domain works directly; a different domain needs a same-origin proxy for signed-in features. See [Install & server setup](/docs/install).
</Callout>
